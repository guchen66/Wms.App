# WMS 仓储管理系统 (WMS-System)

## 📖 项目简介
本项目是一个基于 WPF 构建的企业级 WMS（仓储管理系统），旨在通过现代化的桌面端技术，实现仓储作业的精细化、数字化管理。项目采用标准的 MVVM 架构，注重代码的可维护性与扩展性，是个人积累企业级桌面应用开发经验的实战作品。

## 🛠️ 核心技术栈

| 技术                | 说明                                                  |
| :------------------ | :---------------------------------------------------- |
| **WPF**             | 桌面端 UI 框架，提供流畅的交互体验                    |
| **Prism**           | MVVM 框架，实现模块化架构、依赖注入(DI)及 Region 导航 |
| **SqlSugar**        | 高性能 ORM，支持多数据库及便捷的数据库维护操作        |
| **Mapster**         | 高性能对象映射工具，解耦 Entity 与 ViewModel          |
| **MiniExcel**       | 轻量级 Excel 导入导出工具，避免大文件导出内存溢出     |
| **MySQL**           | 关系型数据库，存储业务数据                            |
| **MVVM + DI + AOP** | 架构模式：数据绑定、控制反转、面向切面编程            |

## 🏗️ 架构设计
- **模块化设计**：基于 Prism 的模块化机制，将基础数据、入库、出库等拆分为独立模块。
- **动态导航**：使用 `Region` 动态加载右侧内容区，左侧菜单通过 `TreeView` 驱动。
- **弹窗交互**：使用 Prism 的 `IDialogService` 处理新增、编辑、确认等高频操作，提升操作连贯性。
- **数据映射**：全面使用 Mapster 进行数据转换，避免手写冗长的属性赋值。

## 📦 模块开发进度

### ✅ 已完成模块
- **首页 Dashboard**：系统概览与核心数据展示。
- **用户管理**：系统用户与角色的增删改查。
- **系统设置**：全局参数配置。
- **报警管理**：库存异常与预警提示。
- *(注：原“订单管理”模块已删除，系统聚焦于纯仓储现场作业)*

### 🚧 待开发核心模块

#### 1. 基础数据管理 (Base Data)
- **商品管理**：SKU 信息维护（条码、规格、单位等）。
- **仓库与库区管理**：定义物理空间结构。
- **库位管理**：精确到货架、层级的存储节点维护。

#### 2. 入库管理 (Inbound)
- **入库单列表**：全局视角查看入库任务状态。
- **收货与上架**：录入实收数量、批次信息，系统推荐库位并确认落位。

#### 3. 出库管理 (Outbound)
- **出库单列表**：全局视角查看出库任务状态。
- **拣货与发货**：展示拣货任务，支持 FIFO（先进先出）策略，复核后扣减库存。

## 🔮 未来扩展规划
- **库存盘点**：全盘/抽盘、差异比对与审核调整。
- **批次与效期管理**：支持商品批次追踪与保质期预警。
- **AOP 审计日志**：全局拦截关键操作，记录操作人、时间与数据变更。
- **内存缓存**：对字典数据进行本地缓存，减少数据库查询。
- **SignalR 实时通知**：新任务或预警实时推送到客户端。
